# 나만의 프롬프트 관리

터미널에서 프롬프트를 추가하고 목록, 카테고리, 검색, 즐겨찾기로 찾아보는 Python 학습용 프로그램입니다.

## 준비물과 실행 방법

Python 3.10 이상이 필요합니다. 외부 라이브러리는 필요하지 않습니다.

1. 이 폴더를 VS Code에서 엽니다.
2. **터미널 → 새 터미널**을 엽니다.
3. `python --version`으로 Python 버전을 확인합니다.
4. `python main.py`를 실행합니다. 메뉴에서 번호를 입력하고 Enter를 누릅니다.
5. 종료하려면 `0`을 입력합니다.

Windows에서 `python` 명령이 인식되지 않는다면 `py main.py`를 시도할 수 있습니다.

## 기능

- 프롬프트 추가: 제목, 내용, 카테고리를 입력합니다. 빈 값은 다시 입력합니다.
- 전체 목록: 제목, 카테고리, 즐겨찾기 여부를 번호와 함께 봅니다.
- 카테고리별 조회: 원하는 카테고리의 프롬프트만 봅니다.
- 검색: 제목이나 내용에 포함된 단어로 찾습니다.
- 상세 보기: 번호를 입력해 전체 내용을 봅니다.
- 즐겨찾기 설정/해제 및 즐겨찾기 목록: 자주 쓰는 항목을 모아 봅니다.

기본 카테고리는 **텍스트 생성, 이미지 생성, 영상 생성, 페르소나, 자동화, 기타**입니다. 프롬프트를 추가할 때 새 카테고리 이름을 직접 입력할 수도 있습니다.

프로그램을 실행하는 동안 추가한 항목과 즐겨찾기 변경은 유지됩니다. 종료한 뒤 다시 실행하면 시작 데이터로 돌아갑니다.

## 시작 데이터 안내

현재 시작 데이터 3개는 이 프로젝트를 위해 새로 작성한 **예시 프롬프트**입니다. 이전 미션에서 작성한 프롬프트가 준비되면 `main.py`의 `initial_prompts()`에 있는 예시를 교체해야 과제의 해당 조건을 충족합니다.

## 파일

- `main.py`: 프롬프트 관리 프로그램
- `hello.py`: Python 설치를 확인하는 첫 연습 파일
- `prd.md`: 과제 요구사항 정리
- `작업-체크리스트.md`: 작업 진행 상태
